# Simulator record
Status: partly implemented in slice S11b-1 (ADR-0012, proposed). Stonecrab-owned; no
upstream parity claim.

Apache PLC4X ships a simulated driver (`SimulatedDriver`), and its Javadoc describes the
address shape `AREA/name:TYPE` with the areas `STATE`, `RANDOM` and `STDOUT`. No part of
the simulated driver's source is inventoried in `upstream/manifest.toml`, so nothing here
is a verified behavioral comparison, and the "Upstream" column says "none inventoried"
where there is nothing to compare. The Stonecrab simulator is not a Modbus simulator and
models no wire protocol; it exists so the `Driver` and `Connection` contracts, the
sensor profiles and the common driver suite can run without a device (CODING_STANDARDS
13.5). The rows give rustdoc `# Compatibility` sections a stable target and tests ids to
cite.

| SIM-ADDRESS-GRAMMAR | None inventoried. The upstream Javadoc describes `STATE\|RANDOM\|STDOUT/name:TYPE` with upper-case type names and a legacy array form (UNVERIFIED against the source). | `SimAddress::parse` reads `STATE\|RANDOM\|SINK/<name>:<type>`, case-sensitive; the type is one of the lowercase scalar names `bool`, `i8`..`i64`, `u8`..`u64`, `f32`, `f64`; the name obeys the `TagId` rules and may contain `/` and `:`; input is at most 256 bytes, so through `parse` a name is at most 247 bytes (`new` allows the full 256). Divergences: `STDOUT` is renamed `SINK` (print macros are denied; writes are counted and discarded); type names are lowercase; the legacy array form is rejected with its own message; the 256-byte bound is new. Every rejection is `InvalidAddress`. `SimAddress` implements `ProtocolAddress` with protocol `sim` and a canonical text equal to the input form. | implemented | `every_area_and_type_parses_and_renders_back`, `the_address_reports_the_sim_protocol_and_its_type_hint`, `a_name_may_contain_slashes_colons_and_interior_spaces`, `empty_input_is_rejected`, `a_missing_slash_is_rejected`, `a_missing_type_is_rejected`, `unknown_areas_are_rejected_including_upstream_stdout_and_lowercase`, `unknown_and_upper_case_types_are_rejected`, `the_legacy_array_form_is_rejected_with_its_own_message`, `a_name_over_the_tag_id_bound_is_rejected`, `the_text_bound_is_exact`, `the_minimal_form_is_exact`, `control_characters_are_rejected_anywhere`, `edge_whitespace_and_empty_names_are_rejected_by_the_tag_id_rules`, `the_name_error_keeps_the_tag_id_failure_as_its_source`, `errors_echo_a_bounded_excerpt_only`, `new_refuses_types_without_a_spelling_and_accepts_every_scalar`, `areas_are_named_and_ordered`, `prop_sim_address_parse_never_panics`, `prop_sim_address_parse_never_panics_on_any_string`, `prop_sim_address_canonical_round_trips`, doctests `SimAddress`, `SimAddress::parse`, `SimAddress::new`, `SimArea` |
| SIM-DEVICE-MODEL | None inventoried. | `SimDevice` holds at most 4096 named `SimTag { value, readable, writable }` behind a poison-recovering `std::sync::Mutex`: `set`, `remove`, `get`, `tags`, `ramp(name, start, step)`, `serve_read`, and the stored settings `latency`, `max_items` and `seed`. A ramp serves its start first and adds the step after every served read in the value's own type with checked arithmetic; when the next value would overflow (or a float sum is not finite) it stops and keeps serving the last value, never wrapping. `SimTag::with_read_counter` returns an `Arc<AtomicU32>` incremented on every served read (the `std`-only form of ARCHITECTURE.md 5.1's `read_side_effect`). Names follow the `TagId` rules. A tag that is not readable refuses reads without counting them. `Debug` prints counts, not values. | implemented | `set_get_remove_and_tags_round_trip`, `names_follow_the_tag_id_rules`, `the_tag_count_is_bounded_but_replacing_is_always_allowed`, `a_ramp_serves_start_then_adds_the_step_on_every_read`, `a_ramp_that_would_overflow_holds_at_the_last_value`, `every_numeric_type_ramps_and_holds_at_its_limit`, `advance_refuses_mismatched_and_non_numeric_pairs`, `ramp_refuses_mismatched_and_non_numeric_inputs`, `ramping_an_existing_tag_keeps_its_flags_and_counter`, `the_read_counter_counts_every_served_read_and_only_those`, `a_tag_that_is_not_readable_refuses_reads_without_counting_or_advancing`, `reading_an_unset_name_is_an_invalid_address`, `a_copy_from_get_does_not_advance_the_stored_ramp`, `latency_max_items_and_seed_are_stored`, `debug_prints_counts_not_values`, `a_panic_while_the_lock_is_held_does_not_break_the_device`, `the_device_is_shareable_between_threads`, doctests `SimDevice`, `SimTag`, `SimTag::serve_read`, `SimDevice::ramp` |
| SIM-RANDOM-SEEDED | None inventoried; the upstream `RANDOM` area is understood to draw from `SecureRandom` (UNVERIFIED), which cannot be seeded. | `SimDevice::random(type)` draws from a seeded xorshift64* generator (`wrapping_mul`, no overflow): integers take the low bytes of one draw, a Boolean its lowest bit, floats are uniform over `[0, 1)`. The seed is fixed by default and set with `SimDevice::with_seed` (S11b-2 reads it from `sim://<device>?seed=`); zero is replaced by a nonzero constant. A type outside the eleven scalars is `InvalidConfig` and still consumes a draw. Divergence: reproducible rather than cryptographic. | implemented | `the_sequence_for_a_fixed_seed_is_pinned`, `a_zero_seed_is_replaced_by_a_nonzero_constant`, `each_scalar_type_is_built_from_the_low_bytes_of_one_draw`, `a_false_boolean_comes_from_a_clear_low_bit`, `every_scalar_type_yields_its_own_type_and_floats_are_in_the_unit_interval`, `non_scalar_types_are_refused_but_still_consume_a_draw`, `random_values_repeat_for_a_fixed_seed_and_differ_between_seeds`, `random_serves_every_scalar_type_and_refuses_the_rest`, doctests `SimDevice::random`, `SimDevice::with_seed` |
| SIM-REALTIME-CLOCK | None (Netty and the Java drivers use the JVM clock). | `RealtimeClock` is the `std`-only `Clock` of the simulator: `now()` is `Instant::now()`, `wall_now()` is `SystemTime::now()`, `sleep_until` is ready on its first poll for any deadline and moves no time. In real-time use a `Delay` script step is a no-op and a `Timeout` step returns `Timeout` directly. Deadlines are compared against the connection's own clock (D9, ADR-0012). | implemented | `it_is_object_safe_and_shareable_as_arc_dyn_clock`, `now_is_the_monotonic_clock_and_wall_now_the_system_clock`, `sleep_until_is_ready_on_the_first_poll_for_any_deadline`, `a_dropped_sleep_has_no_effect`, doctests `RealtimeClock`, `RealtimeClock::new` |
| SIM-DRIVER | None inventoried. | `SimDriver` (scheme `sim`) registers with the `DriverRegistry`, parses `sim://<device>?latency-ms=<n>&seed=<u64>` and `SimAddress` text, and exposes `with_clock` and `with_device`. | planned (S11b-2, after the `Driver` trait of S11a) | none yet |
| SIM-CONNECTION | None inventoried. | `SimConnection` implements read (STATE, RANDOM), write (STATE writable, SINK counted and discarded), the state lifecycle, a single in-flight operation with `Backpressure` for a second one, deadlines and cancellation through the connection's clock, and diagnostics on every error. | planned (S11b-2) | none yet |
| SIM-FAILURE-SCRIPT | None inventoried. | A `FailureScript` of `Delay`, `Timeout`, `Disconnect`, `DeviceException`, `Malformed`, `PartialFailure` and `Backpressure` steps consumed per operation, so the contract suite can drive every failure case without a socket. | planned (S11b-2 and S13) | none yet |
