# Hardware test record: TEMPLATE

> This file is a template. It is not a hardware record and supports no claim. Copy it
> to `docs/hardware/<device>-<yyyy-mm-dd>.md` and fill every field. Fields come from
> docs/SPEC.md "Hardware evidence".

## Support level evidenced

Pick one and justify it: build-tested, simulator-tested, interoperability-tested or
hardware-verified. Hardware-verified is required before claiming support for a particular
device. For RTU, test both real serial electrical behavior and virtual framing.
